About the Project

Twitter Sentiment Analysis Using Machine Learning

This web application predicts the sentiment of Twitter posts using a Machine Learning model. The model analyzes tweet text along with its related topic (such as Borderlands, Amazon, Xbox, etc.) and classifies the sentiment into one of four categories:

  • 😊 Positive
  • 😐 Neutral
  • 😞 Negative
  • ❓ Irrelevant

Project Objective

The objective of this project is to build an intelligent sentiment analysis system that automatically identifies users' opinions from Twitter data. Businesses and organizations can use this information to understand customer feedback, monitor brand reputation, and analyze public opinion.

Dataset Information

  • Dataset: Twitter Sentiment Analysis Dataset
  • Input Features: Tweet Text, Topic (City)
  • Target Variable: Review (Positive, Negative, Neutral, Irrelevant)

Machine Learning Workflow

  1. Data Collection
  2. Data Cleaning and Preprocessing
  3. Text Vectorization using TF-IDF
  4. Topic Encoding
  5. Model Training
  6. Model Evaluation
  7. Prediction through Django Web Application

Technologies Used

  • Python
  • Django
  • Pandas
  • NumPy
  • Scikit-learn
  • TF-IDF Vectorizer
  • Bootstrap 5
  • Joblib

Key Features

  • Predicts tweet sentiment instantly.
  • Simple and user-friendly interface.
  • Machine Learning model integrated with Django.
  • Real-time sentiment prediction.
  • Responsive web design using Bootstrap.

Future Enhancements
