Project Overview

This project uses Natural Language Processing (NLP) and Machine Learning to analyze Twitter posts and predict user sentiment based on tweet content and topic.

The model has been trained on thousands of labeled tweets and is integrated into a Django web application for real-time prediction.

Features
  • Real-time sentiment prediction
  • Machine Learning powered
  • TF-IDF text vectorization
  • Topic-based sentiment analysis
  • Django web application
  • Responsive Bootstrap interface
