# Twitter Sentiment Analysis

## Overview

A Django-based Machine Learning web application that predicts the sentiment of Twitter posts.

## Features

- Real-time sentiment prediction
- Django web application
- Machine Learning model
- Bootstrap UI
- Responsive design

## Technologies

- Python
- Django
- Scikit-learn
- Pandas
- NumPy
- Bootstrap

## Dataset

Twitter Sentiment Analysis Dataset

Target Classes

- Positive
- Negative
- Neutral
- Irrelevant
